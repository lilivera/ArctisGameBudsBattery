# プラグインアイコン

- `icon.png`: 配布定義・README用の512×512 PNG。
- `icon-source.png`: 内蔵の画像生成ツール（image_gen）で作成した原画像。
- 左右のイヤホンとバッテリー残量をモチーフにした独自のデザインです。
- 配布定義の `IconUrl` は `main/images/icon.png` を参照します。リポジトリへの反映後に公開URLから取得できます。

## 生成プロンプト

用途: logo-brand。Arctis GameBuds Batteryという、左右のワイヤレスイヤホンのバッテリー残量を表示するDalamudプラグイン用の、完成品アプリアイコンを1点制作する。
1024×1024の正方形。背景全体は均一な非常に暗いネイビー。中央に大きく、左右一対のステムのないコンパクトな豆型インイヤーイヤホンをシンボルとして描く。左右で向きが鏡対称になる、丸みのある本体と短いイヤーチップ。イヤホンは白〜ごく淡いグレーで、形状がすぐわかる最小限の陰影。ヘッドホンのヘッドバンドやAirPodsの長い軸は描かない。
イヤホン2個を中央上部に余裕を持って配置し、その下に太くてシンプルなミントグリーンの横向きバッテリー記号を1つ。バッテリーは太い輪郭、右端に短い端子、中に大きな3つの充填ブロック。残量監視を連想させる。イヤホンとバッテリーの間には明確な余白。
丁寧にデザインされた、洗練されたミニマルなテックユーティリティのアイコン。輪郭は明快、幾何学的、ほぼフラット。64×64まで縮小しても読める太い形。全体の外周に約10%の安全余白。正面視で中央に整然と配置。文字、数字、ブランドロゴ、SteelSeriesロゴ、透かし、モックアップ、枠の外の影、装飾の火花、細かな模様、背景のグラデーションは禁止。正方形のアイコン1つのみ。
