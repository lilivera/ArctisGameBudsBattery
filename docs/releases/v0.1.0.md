Arctis GameBudsの左右バッテリー残量をFF14内へ表示する初回リリースです。

- 左右個別／低い側のオーバーレイ表示、DTRバー表示
- 文字サイズ・位置・透明度・警告色の設定
- 定期取得、再接続、古い値の識別
- Windows実機で左右残量の取得を確認、自動テスト30件合格

## インストール

Dalamud設定（`/xlsettings`）の「試験的機能 / Experimental」→「カスタムプラグインリポジトリ」に、次のURLを追加して有効にします。

https://raw.githubusercontent.com/lilivera/ArctisGameBudsBattery/main/pluginmaster.json

`/xlplugins`で「Arctis GameBuds Battery」をインストールし、`/gamebuds`で設定を開いてください。

## 対応環境

Windows 10/11 x64、Dalamud API 15、USBドングル接続（VID 1038 / PID 230A）。
ケース残量・Bluetooth単独接続は非対応です。ゲーム内の表示・操作とSteelSeries GGとの同時利用は未検証です。
